📚 电商新用户转化行为分析 | MySQL 数据项目

项目简介：
本项目基于电商新用户行为数据集，使用 MySQL 完成从数据清洗、用户画像、转化漏斗、多维度差异分析到业务结论的全流程分析。目标：定位新用户核心流失环节，挖掘高价值用户特征，为运营优化与产品迭代提供数据支撑。

🎯 分析目标

    清洗数据，保证数据质量
    统计新用户基础画像（年龄、性别、设备、渠道、市场）
    构建转化漏斗，定位流失最高环节
    多维度分析转化率差异（年龄 / 性别 / 设备 / 渠道 / 操作系统）
    提取高转化用户与活跃观望用户特征
    输出可落地的业务优化建议

📊 数据集说明

    来源：和鲸社区公开脱敏数据集
    表名：new_user_behavior
    关键字段：用户访问页面、设备、系统、渠道、年龄、性别、访问页数、转化状态等

🛠 使用工具

    MySQL / Navicat
    Excel（可视化）
    数据分析思路：漏斗模型 + 用户分群

📝 完整 SQL 脚本目录
1. 数据预处理

    新用户筛选
    缺失值填充
    异常值过滤

2. 用户整体概况统计

    年龄分布
    性别分布
    设备 & 操作系统分布
    流量渠道分布
    访问深度分层

3. 转化漏斗分析

    首页 → 列表页 → 详情页 → 支付页 → 确认页
    各环节转化率 & 流失率

4. 多维度转化差异分析

    年龄维度
    性别维度
    市场维度
    设备 & 操作系统维度
    流量渠道维度

5. 新用户典型画像筛选

    高转化用户特征
    活跃观望（低转化）用户特征

🔎 核心结论

    详情页 → 支付页流失最严重（流失率≈88%），为核心优化环节
    桌面端转化率显著高于移动端
    Ads、Seo 渠道用户质量更高，Direct 渠道质量偏低
    访问深度越深，转化率越高
    高转化用户集中在中青年、深度浏览、优质渠道人群
